# xlookup-vlookup-excel-analysis

Overview

This project demonstrates the use of Excel lookup functions, including VLOOKUP and XLOOKUP, for retrieving data from tables and improving data analysis efficiency.

Skills Demonstrated

- VLOOKUP
- XLOOKUP
- IFERROR
- Data Retrieval and Matching
- Combining Text Using "&"
- Excel Formula Optimization

Key Learnings

VLOOKUP

- Searches for values from left to right.
- Requires the column index number.
- Often combined with IFERROR to handle missing values.

XLOOKUP

- Can search in any direction (left, right, up, or down).
- Easier to use and more flexible than VLOOKUP.
- Includes built-in error handling through the if_not_found argument.


Additional Practice

- Combined XLOOKUP results with text using the "&" operator.
- Compared VLOOKUP and XLOOKUP functionality.
- Explored different methods of handling lookup errors.

Files Included

- Excel workbook containing lookup examples and exercises.
- Sample datasets used for practice.

Conclusion

This project helped me understand modern Excel lookup techniques and the differences between VLOOKUP and XLOOKUP. It improved my ability to retrieve, combine, and validate data efficiently in Excel.
